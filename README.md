# SMI Pro 1.2.1 — Windows

Gravador local (Python 3.8+, só biblioteca padrão).

1. Extraia o ZIP
2. `INSTALAR.bat` (primeira vez)
3. `INICIAR.bat` — deixe a janela aberta
4. `CRIAR-AGENDAMENTO.bat` — vigia de hora em hora (e ao ligar o PC)
5. `PARAR-AGENDAMENTO.bat` — quando não quiser mais histórico automático

Se o Kaspersky derrubar o processo, coloque esta pasta e o `python.exe` nas exclusões.

Dados em `dados/`: `papers.csv`, `paper.json`, `snapshots.jsonl`, `eventos.log`, `vigia.log`.

Regras: 1D+1H, zona M15, faixa de liquidez, varredura, close GR, plano do dia.
Paper automático no Setup pronto. Sem dinheiro real.
